# Sources and adaptation

Original scoped-review procedure. The official OWASP Authorization Cheat Sheet and REST Security Cheat Sheet were consulted for authorization boundaries and input/error review. These are external references, not vendored text or an exhaustive security standard.

- [OWASP Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html), consulted 2026-09-14 for authentication/authorization distinction and resource access checks.

- [OWASP REST Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/REST_Security_Cheat_Sheet.html), consulted 2026-09-14 for service trust boundaries.

The executable instructions are maintained here. References establish provenance, not hidden dependencies or authority to change user scope. Upstream updates require review; no automatic synchronization is configured.
